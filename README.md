# xkcd-extended

A simple app for viewing XKCD comic strips, with extended functionality in the form of adding favorites, categorizing favorites, infinite scroll, and previews of previous and next comic strips when viewing a specific comic strip.

React was chosen for this project primarily as an opportunity to gain experience with the most in-demand and mature frontend framework.

While Vue.js functions similarly for a project of this size, React has dominated front-end development since 2013 and offers a more mature, widely adopted ecosystem.

Angular is structurally designed for complex enterprise applications, whereas React's component-based architecture is effective for building smaller web interfaces without the overhead of a heavier enterprise framework.
